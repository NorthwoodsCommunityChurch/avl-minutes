# Hermes proactive loop — design

**Date:** 2026-10-08 · **Approved by Aaron** in chat the same day ("proactive calendar and mail build approved").
**Builds on:** [2026-10-08-hermes-teams-relay-design.md](2026-10-08-hermes-teams-relay-design.md) and
[2026-10-07-hermes-helper-design.md](2026-10-07-hermes-helper-design.md).

## What Aaron asked for

- "The calendar invite for the 2pm changed. Can Hermes see that and agentically let me know? Like: *I saw your
  calendar change. I'll make sure to send you information for that meeting for the new time.*"
- "Is there a way for Hermes to see when I've sent an email, and agentically remove a task I told her I need to do?"
- Standing: never babysit, no polling the model for nothing, one short Teams line when something matters, nothing when it doesn't.

## Shape

```
Power Automate flows ──► OneDrive AI Feed ──► Hermes Helper (indexes every 2 min)
                                                   │ new or replaced records this pass, written in the last 15 min
                                                   ▼
                                        POST http://127.0.0.1:8787/notify  (x-notify-key)
                                                   │
                                        hermes-teams relay: asks Hermes in Aaron's own chat thread
                                        "Feed event (not from Aaron): … Reply with the one line Aaron should
                                         see, or exactly NO_MESSAGE."
                                                   │
                                        Hermes decides, may act (task board), answers
                                                   ▼
                                        relay posts the line to Aaron's Teams chat (proactive message),
                                        or stays silent on NO_MESSAGE
```

Event-driven: nothing runs until the feed changes. Cost per event is one short Hermes run on Puget.

## Pieces

1. **Helper** (`FeedIndexer.refresh()` returns the records it indexed; `FeedNotifier` filters and posts).
   - Which records: calendar records whose action is `updated` or `deleted`, calendar records added for the next 48 hours,
     and mail records with `direction: sent`. Teams chat messages are not forwarded (Aaron reads those himself).
   - Only records whose file is newer than 15 minutes (so a backfill, a first pass, or a restart never floods Hermes), at most
     12 per notify; a recurring-series change collapses to one line per subject ("Sunday Flow + Outlook: 40 occurrences updated,
     next is Oct 15 2:00–2:40 PM").
   - Reads the relay's key from `~/hermes-teams/config/local.json` (`notifyKey`); if the relay is down, drops the batch and logs.
2. **Relay** (`POST /notify`, local only: the Cloudflare Worker forwards only `/webhooks/teams` and `/health`).
   - Requires `x-notify-key` = `config.notifyKey` (generated by `scripts/setup.js`).
   - Needs a home conversation: the relay records the last 1:1 conversation Aaron wrote in (`state.homeConversation`); until he
     has written once, `/notify` answers 409 and the helper logs it.
   - Builds the Hermes input from a fixed template (below), runs it in Aaron's conversation thread (so Hermes remembers what Aaron
     told her), and posts Hermes's reply unless it is exactly `NO_MESSAGE`. One notify at a time; a second arriving while one runs
     waits (same queue as chat messages).
3. **Hermes** (`SOUL.md` rules): how to treat feed events; create a task board card when Aaron says he needs to do something; on a
   sent email, find the open card it completes, move it to the **Done** list (created 2026-10-08 on the To Do board), tell Aaron
   in one line. Never delete a card.

## The event template (relay → Hermes)

```
Feed event (automatic, not a message from Aaron). Decide whether Aaron needs to hear about it.
If yes, reply with only the one or two lines he should see in Teams. If nothing is worth saying, reply exactly NO_MESSAGE.

<record 1 text>
---
<record 2 text>
```

## What Aaron sees

- Calendar: "Your 2:00 Sunday Flow + Outlook moved to 2:00–2:40 on Oct 15; I'll prep for the new time."
- Sent mail that closes a task: "Saw you emailed Kirk about the lobby screens; moved that card to Done."
- Everything else: nothing.

## Testing

- Relay: `node --test` covers the key check, the 409 before a home conversation, the template, NO_MESSAGE silence, and the
  proactive send.
- Helper: MinutesKit tests cover which records qualify, the 15-minute window, the series collapse, and the 12-item cap.
- Live: Aaron moves a test meeting; a line arrives in Teams.
